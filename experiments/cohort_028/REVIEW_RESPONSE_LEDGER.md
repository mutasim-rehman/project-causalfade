# Cohort 028 review-response ledger

The cohort design attributes these methodological prompts to the user-supplied document `CausalFade_Q1_Peer_Review_Report_2026-11-19.docx`, described there as a simulated editorial review rather than an official journal decision. This implementation follows the repository's cohort 028 design; it does not treat the review as external validation.

| Design concern | Implemented response | Remaining boundary |
| --- | --- | --- |
| Graph specificity | Exact observationally matched confounder/mediator pairs, plus added-Z unchanged-answer graph | Two graph classes and two phrasings do not establish domain transfer |
| Arithmetic assistance | Structured rule and score response, replayed by an allowlisted deterministic calculator | Replay identifies a system gain, not an internal cognitive stage |
| Matched controls | Noncausal named-rule tasks under raw and supplied-score representations | Control wording differs semantically from graph selection |
| Response validity | Strict A/B parsers; invalid C remains wrong; raw outputs and stop reasons retained | No output-format repair in primary scores |
| Family dependence | Independent development/validation families and family-level paired contrast | Validation remains selected feasibility evidence, not confirmation |
| Precision claims | No quantized model in this cohort | Later precision study needs separate freeze and power analysis |
