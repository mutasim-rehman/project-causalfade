# Q2_K CPU repacking diagnostic

Hypothesis: the observed malformed 3B Q2_K generations depend on the CPU backend's default weight repacking. Compare default and explicitly disabled repacking using the same model file, release, exact-evidence prompt schedule, greedy settings and output budget. Use four randomly selected balanced families (16 tasks per arm) with the same seed for both arms. This is a targeted operational diagnostic prompted by cohort 001. Inspect valid actions, finish reasons and exact response-text agreement. A null result under this intervention does not establish parity across all runtimes or quantizers.
