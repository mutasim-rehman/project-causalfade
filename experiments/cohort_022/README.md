# Cohort 022: paired independent checkpoint-family development replication

Prepared 16 November 2026 before inference. Eight fresh families use seed 20261118 with the unchanged cohort 021 generator and exact prompts. The 576-task fixture crosses source selection, ordinary, source-guided and neutral-guided decisions on 128 two-source stems, plus 32 randomized-only decisions and 32 direct-identification checks. Both models receive the identical complete seeded shuffle in fresh contexts, for 1,152 scheduled requests. All families remain development-only.

Qwen2.5-7B-Instruct F16 is the existing checkpoint. The independent checkpoint is Mistral-7B-Instruct-v0.3 Q4_K_M from `bartowski/Mistral-7B-Instruct-v0.3-GGUF`, pinned revision `61fd4167fff3ab01ee1cfe0da183fa27a944db48`, Apache-2.0 license; original model is `mistralai/Mistral-7B-Instruct-v0.3`. Only this one independent file was acquired, outside Git. Its measured size is 4,372,812,000 bytes. Model SHA-256s and server hash are in `frozen_run_plan.json`. The family and weight precision contrasts are bundled (Mistral Q4_K_M versus Qwen F16), so this is a checkpoint-family boundary diagnostic, not an isolated family effect.

Execution blocks are fixed: complete Qwen F16 first, then complete Mistral Q4_K_M, regardless of Qwen outcome. Both use existing llama.cpp b12176 CPU server, eight threads, no GPU layers, 2048-token context, F16 KV, greedy decoding, seed 20261118, 64 output tokens, 180-second request timeout, and up to 7200 seconds per session. llama.cpp uses each GGUF's embedded chat template: Qwen ChatML-style and Mistral `[INST]` style. Runtime server logs and config preserve the effective model/template provenance. The single-writer runner records raw attempts append-only and fsynced, schedule, hashes, configuration and session records. Resume only after a budget pause under identical settings; failures remain preserved and are not retried. Do not select conditions, change prompts or swap checkpoints after outcomes.

Analysis first reports each checkpoint's validity, source selection, randomized-only, ordinary, guided and neutral-guided accuracy, activation, beneficial/harmful results and order effects with family intervals. The central diagnostic is family-standardized randomized-only minus ordinary two-source accuracy, with the paired Mistral-minus-Qwen family difference. Joint independent-request patterns do not establish mediation. If both models show competent simple components and the two-source deficit, propose a prospective generalization/confirmation protocol with a new family-cluster power/coverage simulation. If only Qwen shows it, report a checkpoint-specific boundary. If Mistral fails simple components, do not label its two-source score the same phenomenon. No Q4 comparison, quantization inference, mechanism or confirmatory claim is authorized.
