# Cohort 022: independent checkpoint-family development replication

Both frozen blocks completed on the identical eight-family fixture: 576/576 strict-valid responses per model, 1,152/1,152 total, with no infrastructure failures. Qwen ran first in 4,187 seconds (8.3 requests/minute); Mistral followed in 1,902 seconds (18.2 requests/minute). The pre-inference freeze is commit `6019ea7`. The fixture reused cohort 021's task wording, contracts, guidance and generator logic with new seed `20261118`. See the [frozen plan](frozen_run_plan.json), [analysis](development_analysis.json), [Qwen run](run_001_qwen_f16/) and [Mistral run](run_002_mistral_q4/).

| Task | Qwen2.5-7B F16 | Mistral-7B-v0.3 Q4_K_M |
| --- | ---: | ---: |
| Governing-source selection | 128/128 | 64/128 |
| Direct source identification | 32/32 | 32/32 |
| Randomized-only decision | 31/32 | 16/32 |
| Ordinary two-source decision | 56/128 | 64/128 |
| Source-guided decision | 60/128 | 74/128 |
| Neutral-guided decision | 55/128 | 64/128 |

The family-standardized randomized-only minus ordinary two-source accuracy difference was **+53.1 percentage points** for Qwen (eight-family percentile interval +46.1 to +57.8). It was **0** for Mistral (interval 0 to 0); the paired Mistral-minus-Qwen difference was −53.1 points (−57.8 to −46.1). These intervals describe eight development families and are coarse.

Qwen repeated the central descriptive contrast on fresh worlds. It selected the governing source perfectly in separate requests, but ordinary decisions were 43/64 on beneficial interventions and 13/64 on harmful interventions. It activated on 73.4% of ordinary, 92.2% of source-guided and 75.8% of neutral-guided prompts. Source guidance raised activation without a clear aggregate accuracy gain (60/128 versus 56/128). Ordinary conflict accuracy was 16/32 randomized-first and 7/32 historical-first; aligned cells were 16/32 and 17/32. The randomized-first accuracy ceiling was 16/32 in each two-source decision condition, despite 31/32 randomized-only. This is an output pattern, not proof of a particular internal mechanism. Separate source-selection and decision requests cannot identify mediation.

Mistral failed the simple-component qualification. Governing-source selection was exactly 64/128: it was 64/64 when the randomized source was named A and 0/64 when named B. Randomized-only decisions were 16/32, with activation on all 32: 16/16 beneficial and 0/16 harmful. Ordinary and neutral-guided decisions also activated on every prompt and scored 50% in every alignment/order cell. Source guidance changed 10 historical-first conflict decisions from activation to non-activation and raised that cell to 26/32, producing 74/128 guided overall and 92.2% activation. This conditional guidance response does not repair the basic source-selection or randomized-only failures. Direct identification 32/32 shows that the model can read the literal source name, but it does not establish it can apply the governing-source rule or choose correctly from randomized evidence.

**Stopping decision:** the Qwen pattern recurs on fresh worlds, but this independent Mistral checkpoint does not qualify as a positive or negative replication of the same two-source deficit because its simple components fail. Report a checkpoint-specific boundary in this design and stop model shopping and prompt rewriting. The primary development claim is: *Qwen2.5-7B F16 shows a large, repeatable accuracy loss when a historical source accompanies randomized evidence, even while separate source selection remains accurate; extension beyond this checkpoint remains unestablished.* This is not a confirmatory, mechanistic or quantization claim.

The independent model is a different family and uses Q4_K_M weights while Qwen uses F16, so family and precision are bundled. The GGUF uses Mistral's `[INST]` chat template; Qwen uses its ChatML-style GGUF template. Both ran through the same pinned llama.cpp CPU server with greedy decoding, eight threads, 2,048-token context, F16 KV, 64-token response cap and fresh contexts. The independent file is Apache-2.0 licensed, pinned to `bartowski/Mistral-7B-Instruct-v0.3-GGUF` revision `61fd4167fff3ab01ee1cfe0da183fa27a944db48`, 4,372,812,000 bytes, SHA-256 `1270d22c0fbb3d092fb725d4d96c457b7b687a5f5a715abe1e818da303e562b6`. The model file is stored outside Git. No candidate was selected by preliminary task accuracy.

For later confirmation, prospectively freeze a **single** primary family-level randomized-only minus ordinary accuracy contrast, a simple-component qualification rule, and an independent checkpoint selection policy before seeing outcomes. Simulate family-cluster power and interval coverage across plausible within-family correlations, baseline accuracy, order effects, activation bias and qualification failure rates. Include precision-matched models if the goal is to separate architecture from quantization. Use new worlds and keep source-selection as a separate outcome. No Q4 comparison or new inference is part of cohort 022.
