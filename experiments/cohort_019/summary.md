# Cohort 019: within-world response-contract development screen

## Completion and operational gate

The versioned eight-family fixture was frozen before inference at commit `e378c02` with seed 20261115, 256 decision stems crossed with three response contracts, 48 requested-action encoding checks and 16 semantic source checks. Validation confirmed 832 prompts per arm, including 288 semantic-subset prompts. All 43 repository tests passed. The 7B F16 reference completed 832/832 requests on 14 November 2026 with 832 strict-valid, normally stopped JSON responses and no infrastructure failures. It used the existing verified b12176 CPU server, eight threads, no GPU layers, F16 KV, temperature zero and a 64-token cap. The run took 5,805 seconds (96.7 minutes), within its 7,200-second budget. Raw attempts, server logs, schedule, configuration, hashes and session record are preserved in [run_001_7b_f16](run_001_7b_f16/).

The fixed **semantic** competence gate failed. Strict validity was 288/288 against 260 required. Semantic causal accuracy was 73/128 against 80 required. Conflict accuracy was 12/32 randomized-first and 13/32 historical-first, both below 18. Semantic comprehension was 24/32 against 28: all 16 encoding checks passed, but only 8/16 source checks did. On source checks the model chose `activate` on all 16, getting all eight activate targets and none of the eight leave-off targets. The conditional Q4_K_M run was not launched. Cohort 018's official 64/128 failed reference score and all its artifacts remain unchanged.

## Paired contract and task patterns

All figures below use scheduled-task accuracy; all responses were strict-valid. Each contract was applied to the **same** 128 causal and 128 noncausal decision stems.

| Contract | Causal | Matched noncausal | Encoding checks |
| --- | ---: | ---: | ---: |
| Semantic `decision` | 73/128 | 87/128 | 16/16 |
| Neutral forward (K→activate) | 70/128 | 66/128 | 16/16 |
| Neutral reverse (M→activate) | 103/128 | 113/128 | 16/16 |

On identical stems, reverse minus forward accuracy was +25.8 percentage points for causal decisions (eight-family percentile interval +18.0 to +32.0) and +36.7 points for controls (+24.2 to +46.9). Of the 128 causal forward/reverse pairs, 51 changed from activate to leave-off, none changed the other way, and 77 stayed the same. On controls, 41 changed activate→leave-off and eight changed leave-off→activate. The mapping difference therefore occurs in both task types. The neutral contract reversals isolate the token mapping within world; semantic-versus-neutral comparisons also change the output field and value style. Reverse minus semantic accuracy was +23.4 points causal (+17.2 to +28.9) and +20.3 controls (+13.3 to +28.1). Forward minus semantic was −2.3 points causal (−4.7 to −0.8) and −16.4 controls (−22.7 to −9.4). These coarse intervals resample only eight families.

Semantic causal accuracy did not improve with stronger evidence: 37/64 at effect magnitude 0.04 and 36/64 at 0.12. The reverse neutral contract was 48/64 and 55/64 respectively, but that apparent strength pattern is development-only and intertwined with order and action behavior. Semantic randomized-first aligned accuracy was 32/32, while historical-first aligned accuracy was 16/32: a −50-point family contrast (percentile interval −50 to −50). Conflict accuracy was 12/32 versus 13/32 (historical minus randomized +3.1 points; interval −6.25 to +12.5). Thus order remains prominent under the semantic contract, particularly for aligned items. Semantic controls also shifted with order: aligned −50 points (−59.4 to −40.6) and conflict −59.4 points (−68.8 to −53.1). The control pattern makes a causal-specific interpretation of the order effect untenable here, although the tasks differ in instruction semantics.

Isolated action encoding was perfect under all three contracts, but full decisions changed substantially with mapping. This supports a task-context interaction in behavior, not proof that the model first interpreted evidence correctly and then encoded it incorrectly. Source comprehension also failed in a one-sided way; the model's full-decision errors can involve source selection, evidence interpretation, response mapping and action propensity together. Semantic responses were heavily leave-off biased in historical-first decisions, while forward neutral responses were activate biased. Contract-specific SDT coordinates and denominators are in [development_analysis.json](development_analysis.json). They assume an unverified equal-variance latent-evidence model; corrected values at saturated response rates do not establish discrimination or a mechanism. The two strengths and one observational magnitude do not establish a full psychophysical curve.

## Research decision

Revise evidence/source presentation in a **new development fixture** and repeat the semantic F16 competence screen. Retain the semantic output contract as a useful transparent response form for further development, but do not yet adopt this task as a causal-sensitivity measure: its semantic reference failed causal, conflict and source-comprehension cutoffs. Study neutral-token mapping interference separately with within-world twins and matched controls; cohort 019 makes that contrast measurable, but does not identify the internal route. Do not run a precision comparison or proceed to confirmatory collection on this fixture. Once a revised semantic task demonstrates reference competence and robustness, select one primary endpoint and F16–Q4 contrast, simulate family-cluster power/coverage for that design, and freeze a prospective protocol on untouched families. Cohort 016's power calculation cannot be reused.

The 96.7-minute F16 runtime implies roughly twice that compute for a gated two-arm version, plus analysis. All cohort 019 families remain development-only. See [development_analysis.md](development_analysis.md) and [frozen_run_plan.json](frozen_run_plan.json); no 14B inference was repeated.
