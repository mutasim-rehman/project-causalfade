# Cohort 023: Qwen measurement audit (development only)

Prepared before inference on 16 November 2026. This is one bounded Qwen2.5-7B-Instruct F16 fixture on eight new SCM families (seed 20261119). Cohorts 001–022 are untouched. Cohort 022 showed that the independent Mistral checkpoint returned the constant source answer **A** (64/128) and, on ordinary two-source and randomized-only decisions, the constant action **activate** (64/128 and 16/32). Those response policies motivate crossed source-name and answer-order tests here; they are not assumed to explain Qwen or to identify an internal route.

Within each family, the design crosses causal direction (beneficial/harmful), evidence agreement (aligned/conflict), physical source order (randomized/historical first), randomized-source name (A/B), and displayed answer-alternative order (canonical/reversed). One effect strength, 0.12, bounds the fixture. Every two-source cell has three independent fresh-context requests on identical numerical evidence: decision, governing-source selection, and a noncausal PRIMARY-scorecard control. Each direction × source-name × answer-order baseline also has a randomized-only decision and a matched numeric rate-comparison control. Semantic actions and oracles do not change when only presentation changes.

| Block | Per family | Total |
| --- | ---: | ---: |
| Two-source decision | 32 | 256 |
| Governing-source selection | 32 | 256 |

| **Total** | **112** | **896** |

The first four numbered families are the policy-fitting development subset; the last four are held-out development families. The full factorial is balanced within each family. The validator checks task IDs, public prompt reconstruction, both alternatives and their order, physical block order, World oracle arithmetic, rate signs, evidence matching, exact cell coverage and hashes. The separate runner uses one append-only, fsynced attempt per task, an exclusive lock, exact model and source hashes, a complete seeded schedule and strict JSON decoding.

The frozen outcome set is strict validity and stop reasons; beneficial and harmful decision accuracy separately; activation; source-selection accuracy by randomized name A/B; randomized-only minus two-source family-paired accuracy and action flips; matched numeric/noncausal control effects; and cell-level counts with eight-family percentile intervals. Invalid/missing attempts count incorrect. Separate source-selection and decision requests are not mediation observations. Fixed rival policies are randomized source, historical source, first source, last source, always activate, always leave off, first displayed answer, last displayed answer; source-selection also includes always A and always B. Report oracle accuracy, model agreement, and cases where policies predict identically. Fit only the best of four simple action-bias policies (always activate, always leave off, first answer, last answer) on the first four families, breaking ties in that listed order; score it on the held-out four. Agreement does not identify a psychological latent route.

Before seeing outputs, qualification is: at least 95% strict-valid overall; at least 75% source-selection accuracy **for each A and B**; and at least 75% randomized-only decision accuracy **for each beneficial and harmful direction**. Run all 896 conditions regardless of early scores. If qualification fails, report the component/interface boundary and do not interpret a two-source gap as an isolated deficit. If it passes, call the gap robust in this development fixture only if family-standardized randomized-only minus two-source accuracy is at least 15 points overall and at least 10 points in each source-name and answer-order slice, while matched numeric and noncausal controls each reach 75% balanced accuracy by direction. Otherwise report the interface/control boundary and revise the claim. Zero-width intervals from constant policies are not equivalence claims. No Q4 or broad cross-family inference is part of this cohort.

After a robust gap, draft one primary estimand and simulate family-cluster power, false-positive rate and interval coverage before untouched confirmation. A matched-higher-precision Mistral follow-up would require one pinned provenance-compatible checkpoint and a frozen qualification plan first, with no model search by outcomes.

Execution: one Qwen F16 block, eight CPU threads, no GPU layers, 2048 context, F16 KV, temperature 0, seed 20261119, 64 output tokens, 180-second request timeout, 7200-second session budget, and resume under identical settings only after a budget pause. All prompts use llama.cpp's embedded Qwen chat template and one user message in a fresh context. The model and server hashes, fixture hashes, analysis source hashes and schedule are in `frozen_run_plan.json`; results are reported separately after inference.
